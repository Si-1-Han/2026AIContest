# 학교 출입구

`gates.json`은 사용자가 2026-11-10 제공한 본관 주변 지도에서 빨간 원으로 지정한
정문(왼쪽 위), 당정역 방향 입구(왼쪽 아래), 당정초 방향 입구(오른쪽)를 관리합니다.

위치는 제공된 이미지와 기존 캠퍼스 경계·OSM 보행로를 대조한 근사 좌표입니다.
건물 출입구나 당정역·당정초등학교 자체와는 별도 장소입니다.

- `position`: 출입구 표식의 위경도 `[lon, lat]`
- `connections`: 연결할 기존 도로 위 기준점. 파이프라인은 이 점을 간선에 투영해
  간선을 나누고 출입구에 연결합니다. 기준점이 도로에서 2m 이상 벗어나면 생성을 중단합니다.
- `aliases`: 검색과 자연어 안내에서 사용하는 별칭
- `description`: 장소 정보 패널 설명

정문은 기존 교내 진입 도로, 당정초 방향 입구는 본관 동쪽 접근로에 삽입합니다.
당정역 방향 입구는 원본에 빠져 있던 교내 도로와 교외 도로 사이 통로를 보완합니다.
위치를 보정할 때는 연결 기준점도 함께 확인하고 `pipeline build`를 실행합니다.

지도에 표시하는 원은 위치를 알아보기 위한 표식이며 실제 출입구의 크기·형태가 아닙니다.
