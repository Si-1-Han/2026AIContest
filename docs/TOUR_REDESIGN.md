# 거리뷰형 캠퍼스 투어

## 사용 방식

기본 지도에서 **캠퍼스 투어 시작**을 누르거나 안내창에 “캠퍼스 투어 시작”을 입력하면 정문에서 시작한다. 이동 지점 화살표를 클릭하고 화면을 드래그해 둘러본다. 터치 드래그와 키보드 방향키로도 시선을 바꿀 수 있다. 화면 아래 이동 버튼은 화면 밖에 있는 뒤쪽·옆쪽 지점에도 접근할 수 있게 한다.

- 자유 둘러보기: 갈림길을 직접 선택한다. 장소를 고르면 초록 화살표와 미니맵으로 그 장소 주변까지 안내한다.
- 캠퍼스 한 바퀴: 정문 → 본관 → 대학원관 → 디자인관 → GEMI관 → 음악관 → 로뎀관 → 영산비전센터 → 이공관 → 학생회관 → 신학관 → 비전관 → 정문 순서로 안내한다.
- 주요 장소: 본관 → 운동장 → 음악관 → 영산비전센터 → 학생회관 순서로 안내한다.

두 코스 모두 사용자가 화살표를 눌러 이동하며, 장소 주변 도착 후 **다음 장소**를 눌러 안내를 진행한다. 자동 주행은 하지 않는다. **투어 종료 / Esc**로 기존 지도에 돌아간다. 다시 시작하면 정문으로 초기화한다.

## 이동망과 상태

`features/tour/network.ts`가 기존 보행 그래프에서 다음 구간을 제외한다.

- 실내 출입구 접근선과 미확인 계단 간선(사용자 사진/지도에서 확인한 영상비전센터 측면 계단은 투어 전용 경로로 추가)
- 건물 외곽선과 충돌하거나 벽에서 1.4m 미만으로 접근하는 구간
- 캠퍼스 경계와 그 주변 8m를 벗어나는 구간
- 정문에서 이어지지 않는 구간

나머지 간선을 최대 10m 간격으로 나눈다. 현재 데이터 기준 **255개 지점 / 266개 연결 구간**이며, 모든 건물과 등록된 야외시설 주변까지 이어진다. 건물 내부나 운동장 중앙에는 관찰 지점을 만들지 않는다. 기본 관찰 지점은 건물 주변의 안전한 지점이다. 이공관은 신학관 방향 안뜰, 영상비전센터는 1층 앞 계단 진입점으로 안내·바로 이동한다.

`useTourStore`는 활성 상태, 현재/목표 지점, 탐색 이력과 안내 장소를 보관한다. 일반 이동은 실제 연결선을 따라 기본 30m 진행하며, 이동 중 추가 클릭이나 종료 후 늦은 도착 처리는 무시한다. 투어 진입 시 진행 중인 길찾기 요청과 선택 상태를 정리한다.

`StreetViewCamera`는 보행면 위 눈높이를 유지하며 경로의 수평 위치와 높이를 함께 보간한다. 드래그로 수평 360도, 상하 약 60도를 둘러본다. 화면 움직임 줄이기 설정에서는 위치 보간을 생략한다. 종료 시 기존 지도 렌즈와 카메라 컨트롤을 복원한다.

## 외관과 거리

일반 지도는 기존 렌더러를 유지하고 투어에만 `scene/tour` 장면을 사용한다. 층·강의실·실내 모델은 투어에서 렌더링하지 않는다. 외관의 창문도 불투명하다.

사용자가 제공한 사진을 기준으로 건물별 특징을 분리했다.

| 장소 | 반영한 외관 |
|---|---|
| 본관 | 층별 윤곽과 둥근 모서리, 회색 석재 격자, 세로 유리 타워, 상단 교명 |
| 대학원관 | 밝은 상부와 어두운 하부, 반복 창, 돌출 유리부, 건물명 |
| 디자인관 | 밝은 외벽, 넓은 처마, 세로 루버와 유리부 |
| GEMI관 | 청록 유리 외벽, 외부 계단·난간, 노란 돌출 상자, 디자인관 연결통로 |
| 음악관 | 붉은 벽돌·밝은 띠, 붉은 지붕, 중앙 원형 유리부 |
| 영산비전센터 | 유리 저층부, 상부 불규칙 창, 옥상 격자 프레임 |
| 로뎀관 | 낮은 벽돌동, 중정 형태, 녹색 경사지붕 |
| 이공관 | 꺾인 외곽, 밝은 외벽과 아래층의 분홍빛 패널 |
| 비전관 | 크림색 외벽·세로 구획, 중앙 유리블록 느낌의 창 |
| 신학관 | 흰 기둥, 중앙 계단, 어두운 교명 차양 |
| 학생회관 | 청록 커튼월, 짙은 수평 차양, 출입구 교명 |

도로는 합쳐진 아스팔트 면으로 그리고, 그 바깥 양옆의 띠만 인도로 사용한다. 좁은 보행 간선도 통행 가능한 좁은 면으로 연결한다. 적갈색 보도·노란 점자블록·밝은 경계석, 횡단보도와 방지턱, 가로등과 보라색 배너, 소나무·꽃나무·관목을 배치한다. 건물·운동시설·도로 안에는 가로수를 배치하지 않는다. 교차로에서도 차도·인도·점자블록 면이 겹치지 않도록 polygon-clipping으로 차도 면을 뺀다. 운동장은 사진에 맞춰 줄무늬 인조잔디, 축구선·골대와 녹색 펜스로 표현한다. 정문 옹벽 교명과 중앙 갈림길의 흰 교명 조형물은 별도로 표현한다.

창문·수목·도로 장식은 인스턴스로 묶는다. 벽돌/석재 패턴과 교명은 코드로 만든 캔버스 텍스처이며 외부 이미지 다운로드나 API 키가 필요하지 않다.

## 정확도의 범위

사진을 바탕으로 특징을 단순화한 게임풍 재현이며 사진측량 모델은 아니다. 건물 위치·외곽과 층별 윤곽은 기존 지도 데이터를 따른다. 창문 수, 재료 색, 차양·계단·연결통로의 크기와 위치는 시각적 근사값이다. 보이지 않는 뒷면도 같은 재료 규칙으로 보완했다.

투어 전용 높이 모델에서 영비관 1층 앞→건물 저층에 열린 첫 계단→2층 외부 통로→두 번째 계단→쉼터를 연결한다. 통로 위에는 3층 바닥이 남고, 통로 옆 기둥·난간을 배치해 별도 계단교가 아닌 건물과 이어진 외부 동선으로 표현한다. 2층 통로의 갈림길에서 동→북→동으로 꺾어 로뎀관 앞에 도착하며 로뎀관과의 직결 통로는 없다. 쉼터·이공관·학생회관·신학관·비전관은 같은 상부 평지에 놓이고, 쉼터에서 이공관으로 내려가는 구간은 없다. 정문 서쪽, 본관 앞 횡단 도로, 음악관 서쪽·동쪽 연결로, 로뎀관 동쪽 도로의 사용자 빨간 표시를 기존 교차점에 대조해 기존 경사를 높여 약 2~8%의 오르막으로 표현했다. 도로·인도·지형·건물 기초·조경·이동 카메라가 같은 높이 함수를 사용한다. 표현용 상대 높이는 영비관 주차장 7.15m, 2층 외부 통로·로뎀관 10.75m, 상부 평지 14.35m이며 실제 표고·실측값이 아니다. 원본 일반 길찾기 데이터는 별도로 유지한다. 정확한 고도와 경사에는 측량 자료가 필요하다.

## 검증

`npm --prefix web run test:tour`는 정문 출발, 연결성, 전체 장소 접근, 건물 충돌 회피, 이동 간격, 조경 좌표와 배치, 중복 클릭·순간이동 차단, 종료·재시작과 UI를 검증한다. 루트 `npm test`와 CI에도 포함했다. 실제 Chrome 화면에서 거리뷰 장면, 이동 화살표, 안내 UI와 미니맵 렌더링을 확인했다.

## 외관 품질 개선과 Blender 모델

창문을 네 면 프레임·분할 프레임·뒤쪽 음영 면·유리·돌출 창턱으로 분리했다.
반사 환경은 화면의 하늘과 같은 태양 방향으로 생성한다. 유리는 실내가 보이지
않는 물리 재질이며 클리어코트와 낮은 거칠기로 외부 반사를 표현한다. 석재,
벽돌, 보도, 아스팔트, 연석, 점자블록, 나무줄기에 색/노멀/거칠기 맵을 적용한다.

현재 Three.js와 호환되는 SSAO와 normal pass를 사용해 창틀 안쪽·건물 밑의
접촉감을 보강한다. 반해상도와 깊이 기반 업샘플링을 사용하며 블룸은 약하게
적용한다. 그림자 영역은 카메라 주변을 따라간다. 수목은 소나무·활엽수·꽃나무·
은행나무 4종과 형태 변형 3개를 사용하고, 종류별 잎 모양과 높이를 다르게 한다.
배수구는 통행을 방해하지 않는 얇은 격자로만 추가했다.

`tools/blender/build_exteriors.py`는 공유 외관 명세를 Blender에서 가공해 11개
GLB 모델과 편집 원본을 생성한다. 웹은 가까운 모델부터 교체하고 로딩 실패 시
절차적 외관을 유지한다. [원본과 재생성 방법](../assets/tour/README.md).
`test:tour-art`는 산출물 리비전, 파일 해시, 압축 메시 디코딩, PBR 재질과 좌표를
검증한다. 일반 지도 마커는 DOM UI 레이어에서 관리해 투어 진입 시 중첩 React
루트 해제 충돌을 피한다. 검증용 Vite 캐시는 개발 서버 캐시와 분리했다.


## 2026-11-10 사용자 검토 반영

- 교차로의 교차·중첩 인도를 없앴다. 도로를 먼저 합친 뒤 그 외곽에만 인도·연석·점자블록을 만들고, 주차장 면도 인도에서 제외한다. 도로·보도에 재질 입자와 포장 패턴을 추가했다.
- 영산비전센터 앞을 포함한 모든 주차장에서 직육면체 차량 모형을 제거했다. 아스팔트와 흰 주차선만 사용하며 주차선은 주차장 외곽 안으로 자른다.
- 운동장 옆 통행로를 가리는 미분류 배경 구조물을 투어 장면에서 제외했다. 배경 건물이 교내나 통행 면을 점유하는지도 검사한다.
- 사용자 제공 지도에 맞춰 동쪽 순환도로에서 이공관 앞으로 꺾이는 연결 구간을 보완했다. 좌표는 기존 지도 위에서 맞춘 근사값이며 `SOUTH_LINK`에 분리했다.
- 건물 바로 이동: 투어 메뉴에서 건물을 고르면 도로 위의 가까운 관찰 지점으로 즉시 이동하고 건물을 바라본다. 이동 중 선택해도 이전 이동을 취소한다. 실내나 건물 중앙으로 이동하지 않는다.
- 기본 앞뒤 이동 거리를 30m로 바꿨다. 내부의 촘촘한 연결선을 따라 이동하므로 굽은 길을 대각선으로 관통하지 않는다. 30m 지점이 간선 중간이면 그 위치를 나누어 정확히 정지한다. 방향이 모호한 갈림길·막다른 길·안내 목적지에서는 더 짧게 멈추고 실제 거리를 버튼에 표시한다. 건물 바로 이동은 이 거리 제한의 예외다.
- 조경은 원뿔/구체 수관에서 굽은 줄기·가는 가지·불규칙한 잎 무리로 교체했다. 소나무·활엽수·꽃나무 및 낮은 관목의 높이와 형태를 다르게 하고, 잎의 알파 텍스처와 부드러운 그림자를 적용했다. 화면 주변을 따라가는 그림자 영역으로 가까운 수목의 선명도를 높였다.
- 11개 건물 전체에 카메라 쪽 외벽을 따라가는 건물명 태그를 추가했다. 수목과 외부 계단은 이름을 가리지 않으며 다른 건물 뒤의 이름은 숨긴다. GEMI관은 공식 데이터명인 환경친화연구동과 함께 선택할 수 있다.
- 검증에는 차도/인도/점자블록 면의 겹침 없음, 주차장 내부 인도·블록 제거, 누락 연결길, 정확한 30m 및 굽은 길 이동, 전체 건물 바로 이동과 취소 처리를 추가했다.

정문→본관 오르막 양옆에는 교명 석재 옹벽과 상단 난간을 배치한다. 본관 입구는 두 번의 짧은 계단(각 5단)과 넓은 중간참으로 구성한다. 이공관 출입문·차양은 신학관 방향 안뜰에만 놓고 로뎀관을 향한 면에는 만들지 않는다.

정문 오르막 본관 쪽 옹벽은 첫 보도 구간 끝에서 종료해 본관 진입 방향을 비운다. 이 오르막의 가로등은 제외하고, 가까운 주차장 접근선이 만들던 중복 보도 띠를 단일 차도·양옆 보도로 정리한다. 보도의 횡방향 고도도 도로와 같은 경사면에 맞춘다. 영비관 첫 계단은 건물 정면에서 곧바로 오르는 방향으로 배치하며, 2층에서는 모서리 참을 지나 기존 외부 통로·로뎀관 갈림길·쉼터 계단으로 이어진다. 계단 끝에는 둥근 보도 덮개가 디딤면 위로 겹치지 않게 한다.
