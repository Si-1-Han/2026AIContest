# 2026-11-19 · 상현 · 거리뷰 이동 효과음 추가

이날 작업에는 OpenAI Codex를 사용했다.

## 로컬 웹과 API 실행

사용자는 웹을 API에 연결해 실행해 달라고 요청했다. Codex는 누락된 3D 의존성을 설치하고 웹과 FastAPI를 실행했다. 웹을 통한 캠퍼스 API 응답과 웹 빌드를 확인했고, 이후 실행에는 프로젝트 루트에서 `npm.cmd run dev`를 사용하도록 안내했다. 당시 길안내 챗봇은 규칙 기반 모드로 실행됐다.

## 재생 시점

거리뷰에서 이동 입력을 한 뒤 실제로 다른 지점으로 이동할 때 짧은 효과음을 재생하도록 했다. 이동 경로에 두 지점 이상이 있을 때와 건물 바로가기로 현재 지점과 다른 곳에 이동했을 때 재생한다. 같은 지점을 가리키는 입력에는 효과음을 재생하지 않는다.

## 효과음 구현

첫 구현은 약 0.28초였다. 사용자가 소리가 ‘착!’처럼 들린다며 ‘슈웅~’처럼 이어지기를 원해, 재생 시간을 늘리고 소리가 부드럽게 커졌다가 잦아들도록 조정했다. 사용자가 보낸 화면은 공중 자유 시점이었으므로, 거리뷰로 돌아가 이동 화살표를 눌러 확인하는 방법을 안내했다.

Web Audio API로 약 0.56초 길이의 잡음을 생성하고, 대역 통과 필터로 음색이 올라갔다 내려오도록 했다. 볼륨도 점차 커졌다가 사라지도록 조절했다. 오디오 컨텍스트와 잡음 버퍼는 재사용하고, 재생을 마친 오디오 노드는 연결을 해제한다. 브라우저에서 오디오를 사용할 수 없는 경우에도 거리뷰 이동은 이어진다.

구현은 `moveSound.ts`에 추가하고 거리뷰 상태를 관리하는 `useTourStore.ts`에서 호출하도록 연결했다. 근거는 커밋 `0c911e8`이다.

## 검증과 커밋

타입 검사는 통과했다. 투어 테스트는 정문 진입로 옹벽 높이 검사에서 실패했고, 브라우저에서 효과음을 직접 청취한 결과는 대화에 남아 있지 않다. 사용자가 Git 작성자 정보 오류를 공유해 저장소 범위에서 이름과 이메일을 설정하는 방법을 안내했다. 효과음 추가 커밋은 Git 이력에서 확인했다.
