# 2026-11-17 캠퍼스 지형·본관·음악관 수정

사용자가 제공한 최신 11개 이미지 중 마지막 세 장의 실제 거리 사진을 지형 관계의 기준으로 삼았다. 높이는 측량값이 아닌 모델의 상대 고도다.

## 반영

- 대학원관 앞 분수 구역 전체에서 자동/수동 나무와 관목을 제외하고 잔디 메시를 잘랐다. 빈 구역은 도로 경계를 공유하는 포장면으로 채웠다. 둥근 분수와 본관 방향 교명 표지판은 유지했다.
- 본관 패드 높이가 외벽 밖 낮은 지면으로 갑자기 전파되지 않게 했다. 건물 내부 지형도 제거했다. 1층 외벽 앞 낮은 면과 앞마당 사이를 별도의 일정한 경사면으로 연결했다.
- 본관 2층 계단·앞마당, 3층 진입로·공원 아래를 기초 높이까지 채우고 콘크리트 측면으로 닫았다. 단순한 얇은 판 아래의 빈 공간을 제거했다. 계단 조경은 바로 옆의 작은 두 구역에만 둔다.
- 음악관 앞 작은 주차장은 상대 고도 5.2, 영비관 앞 주차장은 7.15로 구분했다. 음악관 이후 직선 도로와 양옆 보도가 같은 횡단 높이를 공유하며 올라간다. 주차장 입구는 별도 경사로로 연결했다.
- 음악관 옆 실제 식재 둔덕·옹벽·은색 난간을 추가했다. 둔덕을 뚫고 지나던 잘못된 연결을 제거하고 작은 주차장 접근을 음악관 앞쪽 직선 보도에 연결했다.
- 주차장에서 보이는 음악관 정면 방향을 남쪽으로 수정했다. 넓은 석재 박공, 창, 중앙 곡면 유리 계단실과 서측 세로 유리를 사진 비례에 맞춰 다듬었다.
- 기존의 일정한 보도 폭, 차량 진입부 개구부, 균일한 주차 칸, 주차장 안 인도 조각 제거를 유지했다.

`npm --prefix web run models:site -- --blender /path/to/blender`는 실제 웹 지형·포장·옹벽과 Blender 건물을 함께 렌더한다. 검토 이미지는 `assets/tour/reviews/2026-11-17/`의 여섯 시점이다. 검토용 수목 수관만 간소화했으며, 분수 표지 글자 캔버스는 검토 렌더에 포함하지 않는다.

브라우저는 Chrome만 사용했다. CUA의 접근성 상태는 투어를 표시하지만 캡처는 이전 전체 지도 화면을 반복 표시하는 불일치가 있어 최종 Chrome 화면 검증을 완료했다고 주장하지 않는다. 형상 검증은 Blender 렌더와 실제 메시 검사로 수행했다.
