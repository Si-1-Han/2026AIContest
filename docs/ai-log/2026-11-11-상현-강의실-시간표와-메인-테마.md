# 2026-11-11 · 상현 · 강의실 시간표와 메인 테마

## 로컬 실행과 3D 성능 점검

사용자는 Python 가상환경을 만들고 웹을 백엔드 API에 연결해 실행해 달라고 요청했다. Codex는 `backend/.venv`에 Python 3.12와 의존성을 준비하고, Vite 개발 서버의 `/api/v1` 프록시를 통해 FastAPI가 HTTP 200을 반환하는 것을 확인했다. 백엔드 상태 응답에서는 건물 11개와 경로 노드 150개를 확인했다.

사용자가 데스크톱에서만 3D 화면이 느리다고 보고했다. Codex는 렌더링 배율과 그림자 설정을 점검하고, 사용자가 보내준 `chrome://gpu` 결과에서 Chrome이 소프트웨어 렌더러인 `Microsoft Basic Render Driver`를 사용하고 있음을 확인했다. 그래픽 가속과 Windows의 앱별 GPU 설정을 안내한 뒤 사용자가 문제가 해결됐다고 답했다. 어떤 설정으로 해결됐는지는 대화에 남아 있지 않다.

## 호실 데이터 자동 반영

OpenAI Codex로 호실 원본 JSON을 저장하면 Vite가 변경을 감지해 데이터를 다시 생성하고 개발 화면에 반영하도록 했다. 개발 API 캐시와 경로 엔진도 함께 갱신하고 로컬 Python 가상환경에서 실행할 수 있게 했다. 기존 `rooms.json` 편집 내용을 보존했으며, 타입 검사와 API 캐시 회귀 테스트, 백엔드 테스트로 확인했다.

편집한 호실 정보가 지도에 바로 나타나려면 브라우저가 읽는 생성 데이터와 개발 API가 쓰는 데이터가 함께 갱신되어야 했다. 개발 서버에서 원본 변경을 감지한 뒤 Python 변환을 실행하고, 변환이 끝나면 화면에서 새 데이터를 가져오도록 연결했다. 경로 엔진을 같이 갱신해 화면의 호실 정보와 경로 계산이 동일한 데이터를 사용하도록 했다.

## 학생회관 호실 배치 수정

- **1층** · 사용자가 두 호실의 크기를 맞바꾸기로 결정했다. Codex는 위치를 유지한 채 경계를 이동해 102호를 약 119㎡, 103호를 약 52㎡로 맞췄다. 스터디라운지와 인터넷카페는 스터디라운지로 통합했고, 103호 상세 설명에는 `공실`을 넣었다. 사용자가 편집기에서 이전 값을 보고 있다고 알려 원본 JSON의 저장값을 다시 확인했다.
- **2층** · 215·216·217호를 총학생회사무실로 통합하고 세 호실 번호 모두로 검색할 수 있게 했다.
- **3층** · 총학생회 회의실과 대회의실을 총학생회 대회의실 316호로 통합했다. 두 명칭으로 검색할 수 있게 했다.

당시 Codex 대화에서 배치 도형과 API 반영을 확인했고, 호실 배치와 시간표 변경은 커밋 `4e0ce0f`에 포함됐다.

## 강의실 시간표 변환과 표시

- **화면 연결** · 학생회관 101호를 선택했을 때 출발·도착 버튼 아래에 시간표를 표시하는 작업으로 시작했다. 강의실 ID로 시간표를 불러오고, 요일을 첫 열에 배치한 표에 연속 수업 칸 병합과 가로 스크롤을 적용했다.
- **화면 피드백 반영** · 사용자 요청에 맞춰 요일을 위쪽 열로, 시간을 왼쪽 행으로 옮겼다. 화면 눈금은 1시간 단위로 두고 30분 수업은 반 칸, 90분 수업은 한 칸 반을 차지하도록 했다. 수업 블록에는 과목명과 교수명을 표시하고, 색칠된 영역 어디를 클릭해도 과목 상세 모달이 열리도록 했다.
- **전체 시간표 변환** · 재사용 가능한 TSV 변환기로 첨부 시간표를 장소별 JSON 93개로 변환하고, 그중 83개를 호실에 연결했다. 위치 정보가 없거나 미개설인 수업은 제외했고, 지도와 연결되지 않은 10개 장소는 사용자 요청에 따라 데이터만 저장했다. 제외·중복 내역도 기록했다.
- **겹치는 수업과 분반 표시** · 같은 호실·요일에 겹치는 수업은 나란히 배치했다. 과목명·교수·시작 및 종료 시간이 모두 같은 수업은 한 칸으로 통합하고, 상세 모달에서 분반별 과목코드·정원·대상·비고와 과목 전체 일정을 확인할 수 있게 했다. 원본 JSON을 보존하고 호실별로 필요한 시간표만 불러오도록 했다.
- **검증** · 백엔드 테스트 29개를 통과했고, 원본 수업 블록 709개와 통합 그룹 15개를 확인했다. 수업 배치, 분반 구분, 모달의 서버 렌더링, 타입 검사와 배포 빌드도 확인했다. 브라우저 시각 검증은 기록에 없다.
- **근거** · OpenAI Codex 작업 기록과 커밋 `4e0ce0f`.

분반 통합 기준은 과목명만으로 정하지 않았다. 같은 과목이라도 교수, 요일, 시작·종료 시각이 다르면 별개 수업으로 남겼다. 화면에서 여러 분반을 한 칸으로 보여줄 때도 상세 모달과 원본에는 분반 정보가 각각 남아 있어, 표를 간결하게 읽으면서 필요한 수업 정보를 확인할 수 있다.

## 캠퍼스 메인 테마

캠퍼스 메인 테마 음원과 웹 배경음악 컨트롤의 초기 구현을 추가했다. 11월 11일은 음원이 프로젝트에 처음 추가된 날이다. 근거는 커밋 `5d7e685`다.

초기 컨트롤에는 시작·일시정지 버튼과 볼륨 슬라이더가 있었다. 기본 볼륨은 25%로 설정했고, 사용자 입력으로 재생이 시작되면 메인 테마를 반복 재생하도록 했다. 재생이 실패하면 화면에서 다시 시도할 수 있도록 상태 메시지를 표시했다.
