# 2026-11-10 · 유재웅 · 투어 외관 품질과 Blender 모델

- 도구: Codex, Blender 4.5.15 LTS(Python 자동 생성), Three.js
- 시킨 것: 창문 프레임·유리 재질, 그림자·AO, 외벽 몰딩·난간, 도로 디테일, 나무 종류·크기를 개선하고 Blender 건물 모델을 연결
- 얻은 것: 11개 외관 GLB, 편집 가능한 Blender 원본, 건물별 Cycles 검토 이미지, 공유 외관 명세와 재생성 스크립트, PBR 재질·하늘 반사·SSAO, 4종 수목과 3개 형태 변형, 배수구 디테일
- 에셋 지시: 대화에서 제공한 건물 사진과 지도 윤곽을 바탕으로 외관만 재현. 창틀·창턱·몰딩·난간과 모서리 베벨을 보강하고 실내는 생성하지 않음
- 소재·출처: 색/노멀/거칠기 및 잎 텍스처는 코드로 생성. 사용자 사진을 텍스처로 복제하지 않고 유료 모델·외부 사진 에셋을 추가하지 않음. 원본 지도는 기존 ODbL 출처 표시를 유지하고, 로컬 Draco 디코더는 Apache-2.0 라이선스를 동봉
- 품질의 범위: 사진을 참고한 근사 외관 모델. 실측 치수·사진측량 모델 및 보이지 않는 면의 정확한 복원은 아님
- 최적화: 11동 총 약 18.5MB, 130m 안의 모델만 로드하고 실패·로딩 중에는 절차적 외관 유지. 투어 장면은 별도 청크로 로드
- 검증: 백엔드 30개, 브라우저 경로 69개, 투어 연결망 검사와 빌드 통과. 압축 메시 138개를 실제 디코딩해 파일·좌표·재질·소스 일치를 확인. 지도↔투어 재진입 및 음악관 바로 이동 확인. 중첩 DOM 해제, AO 버전 호환, 후처리 톤 매핑 누락과 GLB 외벽 색상 누락 수정 및 색상 회귀 검사 추가. [모델 원본과 사용법](../../assets/tour/README.md)
- 사용량: 확인 가능한 토큰 통계 없음
- 사람이 고친 부분: 후속 외관 검토 예정

## 후속 색감 조정

- 요청: 전체 분위기에 색감을 조금 더 추가
- 변경: 투어 하늘과 반사 환경의 대기색을 맞추고, 안개를 줄여 원거리 색상 유지. 잔디·수목의 초록, 꽃의 분홍, 운동장·테니스장과 보도의 색을 보강. 톤 매핑 뒤에 약한 채도·대비 보정 추가
- 검증: TypeScript 및 프로덕션 빌드 통과. 브라우저의 투어 화면에서 조경·보도·외관 색상 확인

## 흰빛과 하늘 재조정

- 요청: 하늘을 더 진하게 하고 건물을 포함한 전체 장면의 허연 느낌 감소
- 변경: 산란 하늘을 파랑 그라데이션으로 교체하고 동일한 환경을 유리 반사에도 사용. 기본 AgX 대신 Neutral 톤 매핑으로 외벽·창문 원색을 보존하고, Bloom·가까운 안개를 줄임. 그림자 안의 건물 디테일은 중성 주변광으로 유지하고 대비를 보강
- 검증: 타입 검사·프로덕션 빌드와 정문/본관 주변 브라우저 화면 검토
