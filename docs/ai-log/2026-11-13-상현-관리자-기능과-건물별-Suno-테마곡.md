# 2026-11-13 · 상현 · 관리자 기능과 건물별 Suno 테마곡

## 캠퍼스 관리자 기능

관리자 화면과 캠퍼스 화면에서 호실과 시간표 등 캠퍼스 데이터를 추가·수정·삭제하도록 관리자 UI와 API를 연결했다. 데이터 변경 후 새로고침과 접근 제어를 검사하는 테스트를 추가했다. 근거는 커밋 `7f2a2d7`이며, 통합 검증은 11월 18일 기록에 정리했다.

- **관리자 접근** · 로그인, 현재 세션 조회, 로그아웃 API를 마련하고 화면이 관리자 상태를 확인하도록 연결했다.
- **데이터 편집** · 건물, 호실, 수업을 조회하고 편집하는 API를 만들었다. 별도 관리자 화면에서 데이터를 관리하고, 캠퍼스 화면에서도 선택한 호실의 정보를 바로 수정할 수 있도록 했다.
- **반영 확인** · 저장한 데이터 변경을 캠퍼스 화면에서 다시 불러오는 흐름과 관리자 권한에 따른 화면 동작을 확인할 수 있도록 테스트를 추가했다.

## 건물별 Suno 테마곡

- **도구** · Suno, OpenAI Codex.
- **기획과 적용** · 건물별 음악 스타일과 재생 시점을 정하고, 건물 11개 동의 테마곡을 웹에 추가했다. 선택한 건물에 따라 배경음악이 바뀌도록 연결했다.
- **스타일 기획과 프롬프트** · Codex가 제안한 건물별 콘셉트 전문을 상현이 영어로 번역해 Suno에 입력했다.
- **이용 조건과 날짜** · 생성 시점의 이용 조건과 공개·상업 이용 범위는 프로젝트 기록에서 확인되지 않았다. 11월 13일은 음원을 프로젝트에 추가한 날짜다.
- **근거** · 커밋 `99ef2a8`과 11월 20일 결과 보고서 작성 대화.

테마곡은 캠퍼스 메인 테마와 건물별 곡의 용도를 나눠 연결했다. 건물이 선택되지 않은 상태에서는 메인 테마를 재생하고, 건물을 선택하면 해당 건물의 테마를 불러오도록 했다.
