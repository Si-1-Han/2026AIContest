# 2026-11-10 · 유재웅 · 1인칭 캠퍼스 투어

- 현재 상태: 아래는 사용자 요청으로 제거한 이전 자동 이동 구현의 기록이다. 새 거리뷰 구현은 [거리뷰 투어 기록](2026-11-10-유재웅-거리뷰투어.md)과 [설계](../TOUR_REDESIGN.md) 참고
- 도구: Codex
- 시킨 것: 정문에서 출발해 캠퍼스를 전체 순회하는 거리뷰 느낌의 1인칭 투어 구현
- 얻은 것: 보행로 기반 전체·주요 장소 코스, 눈높이 카메라, 드래그·터치 시선 조작, 키보드·버튼 이동, 자동 재생·일시정지·속도 조절, 진행 바·미니맵, 종료 후 세션 내 이어보기, 자연어 투어 시작
- 경로: 전체 약 2,452m, 주요 장소 약 1,235m. 등록된 전체 장소 주변을 지나 정문으로 복귀. 기존 지도·길찾기 데이터는 수정하지 않고 투어 전용 그래프 구성
- 검증: 건물 관통·벽 근접 간선 제외, 원본 데이터 보존, 코스 범위·보간·재생·정지·재개·완주·UI 회귀 테스트. Chrome에서 투어 메뉴·전체 코스 시작·1인칭 화면·미니맵·진행 UI 확인
- 범위: 기존 3D 모델 기반 가상 투어. 이동은 코스 위에서 진행하며 실사 파노라마는 사용하지 않음. 현재 지형 높이 데이터에 맞춰 지면 기준 1.7m 눈높이 사용
- 사용량: 확인 가능한 토큰 통계 없음
- 사람이 고친 부분: 후속 검토 예정
