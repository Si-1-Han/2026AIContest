# 2026-11-10 · 유재웅 · 거리뷰형 캠퍼스 투어 재구현

- 도구: Codex
- 시킨 것: 사용자가 제공한 건물별 사진·거리뷰 사진을 기준으로 외관 중심의 1인칭 투어를 다시 구현. 이동 지점 클릭과 드래그 방식 사용
- 얻은 것: 투어 전용 밝은 외관 장면, 구름·수목·도로·보도·운동시설, 11개 건물별 외관 특징과 건물명, 정문 출발 거리뷰 카메라, 자유·전체·주요 장소 안내, 미니맵, 종료 후 기존 지도 복귀
- 이동망: 정문에서 연결된 215개 지점·224개 구간. 이동은 인접 지점끼리만 가능하며 건물 관통선·실내 접근선·교외 단절 구간 제외
- 검증: 백엔드 30개 테스트, 기존 검색·안내·브라우저 길찾기 69개, 신규 투어 네트워크·상태·조경·UI 검증 및 프로덕션 빌드 통과. Chrome에서 투어 장면·이동 지점·미니맵 렌더링 확인
- 이미지/소재: 사용자 제공 참고 사진의 특징을 코드로 재구성. 사진 파일을 서비스에 복제하지 않음. 석재·벽돌·교명 텍스처와 3D 도형은 코드 생성. 지도 출처 표기 유지
- 범위: 실사 파노라마나 사진측량 모델이 아닌 게임풍 근사 외관. 실제 경사·치수와 보이지 않는 면은 추가 확인 필요. [설계·제약](../TOUR_REDESIGN.md)
- 사용량: 확인 가능한 토큰 통계 없음
- 사람이 고친 부분: 후속 검토 예정

## 사용자 검토 후 개선

- 사진의 교차 인도를 확인해 도로 면을 합치고 그 바깥 양옆에만 보도·연석·점자블록을 생성하도록 변경. polygon-clipping(MIT)을 npm 의존성으로 추가
- 주차장 차량/블록 모형 제거, 흰 주차선만 유지. 운동장 옆 통로를 가리는 미분류 배경 구조물 제외
- 제공된 지도에 맞춰 동쪽 도로와 이공관 앞 연결길 추가. 초기 이동망 223개 지점·233개 구간
- 기본 이동 30m, 실제 연결선을 따라 굽은 길 이동, 갈림길·목적지 앞 정지. 건물 선택 시 즉시 관찰 지점으로 이동하고 이전 이동 취소
- 잎·가지 기반 나무와 관목, 포장 재질, 주변을 따라가는 부드러운 그림자 적용. 외부 사진/모델을 다운로드하지 않고 코드로 생성
- 11개 건물 이름표, GEMI관 별칭 표시. Chrome에서 정문 장면, 30m 이동과 건물 바로 이동 메뉴/결과 확인
- 검증: 전체 npm test 통과(백엔드 30개, 기존 브라우저 경로 69개, 신규 도로 면/주차장/조경/30m/바로 이동 검증, TypeScript·프로덕션 빌드). 마지막 이름표 수정 후 투어 검증·빌드 재통과
