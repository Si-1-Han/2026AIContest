## 캠퍼스 건물 11개 외관 개선

전체 지도에 공통으로 적용되던 하늘색 건물 외형을 건물별 외벽과 지붕 색으로 바꿨다. 사용자가 건물마다 실사진을 제공하고, Codex가 사진에서 멀리서도 구별할 수 있는 특징을 골라 층별 외곽선에 맞춰 구현했다. 이공관은 실사진으로 색을 맞추고, 창의 크기와 배열은 사용자가 제공한 거리뷰 3D 화면을 참고했다.

| --- | --- |
| 본관 | 회베이지 석재 외벽과 둥근 타워를 감싸는 청회색 창 띠 |

| GEMI관 | 운동장 쪽 격자형 유리 외벽, 반대쪽 외부 계단과 노란색·주황색 돌출창 |

사용자가 화면을 확인한 뒤 음악관은 아치와 둥근 돌출창의 앞뒤 위치를 맞바꾸고 1층 문·차양 표현을 제거했다. 붉은 벽돌 부분의 창은 전 층에서 같은 크기로 맞췄다. 영상비전센터 6~10층은 창 높이와 크기를 통일하고, 큰 고정창과 작게 열린 여닫이창을 한 세트로 배치했다. 비전관 엘리베이터는 넓은 면에서 좁은 끝벽의 두 창 사이로 옮겼고, 이공관은 기존 돌출부 두 면을 유리로 표현했다.

웹 빌드와 타입 검사를 거쳤고, 11개 건물 68개 층에서 외관 지오메트리가 생성되는 것을 확인했다. 후속 수정은 모델 좌표 검사로 확인했다. 근거는 커밋 `26d4920`과 11월 20일 Codex 대화다.

## Suno 음원 출처와 결과 보고서

오른쪽 아래 배경음악 버튼 옆에 `AI 생성 음악 · Suno` 문구를 추가했다. 브랜치 전환 과정에서 문구 변경이 stash에 들어가 머지 결과에서 빠진 것을 확인했고, 해당 문구를 복원한 뒤 `a115caf`에 반영했다.

결과 보고서에는 캠퍼스에 익숙하지 않은 신입생과 다른 건물에서 수업을 듣는 재학생이 강의실 위치를 찾기 어려운 상황을 배경으로 정리했다. 이를 해결하기 위해 3D 캠퍼스 지도에서 건물과 강의실을 찾고 자연어로 길을 물을 수 있도록 구현한 내용을 담았다. AI 활용 항목에는 Codex로 프로젝트를 구현하고 점검한 과정과 Suno로 만든 테마곡을 웹에 적용하고 출처를 표시한 과정을 정리했다.

## 웹 CI 실행 환경 수정

GitHub Actions의 웹 테스트 실패 사례를 확인하고, 웹 작업에서 Node.js 의존성만 설치하던 실행 순서에 Python 의존성 준비 단계를 추가했다. `astral-sh/setup-uv@v6`로 uv를 준비하고, `backend`에서 `uv sync --frozen`을 실행한 뒤 웹 테스트 단계로 넘어가도록 했다.

CI 실행 환경에서 Python이 준비되지 않은 문제와 이미 재현되던 거리뷰 모델 검사의 실패를 구분해 기록했다. 근거는 워크플로 수정 커밋 `5edc6a8`과 11월 20일 Codex 대화다.
