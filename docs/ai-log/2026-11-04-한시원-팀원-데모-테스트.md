# 2026-11-04 · 한시원 · 팀원 데모(Pydeck·PyVista·Panda3D) 테스트 방법

- 도구: Claude (claude.ai, 원격 기기 연결) · Claude Opus 5.5
- 시킨 것: 팀원이 같은 캠퍼스(건물 11개)를 Pydeck(웹 HTML)·PyVista(웹 앱)·Panda3D(데스크톱 창) 세 가지로 만든 데모를 어떻게 테스트하고 실행하는지
- 얻은 것:
  - 의존성 설치 후 Pydeck JavaScript 상호작용 테스트 전부 통과 확인. PyVista 테스트는 그래픽(OpenGL)이 없는 환경이라 포트 관련 테스트만 통과
  - 발견한 문제: `campus_shared/verify_reference.py`가 없는 `desktop_demo` 모듈을 import해서 실행 불가, README는 `panda3d/` 폴더를 가리키지만 실제 폴더는 `ex_panda3d`
  - `git status`의 42개 수정 파일은 추가·삭제 줄 수가 같아 줄바꿈(CRLF/LF) 차이로 판단 → `core.autocrlf` 설정 권장
  - Windows PowerShell 실행 절차: 가상환경 생성, `requirements-demos.txt`·`pyvista/requirements.txt` 설치, 데모별 실행(Pydeck은 브라우저, PyVista는 `http://127.0.0.1:8080`, Panda3D는 게임 창·Esc 종료), Panda3D DLL 차단 시 `ex_panda3d/TROUBLESHOOTING.md` 참고
- 사용량: 프롬프트 2회. 토큰 통계는 claude.ai 화면에서 확인할 수 없음
