- 도구: Claude (claude.ai) · Claude Opus 5.5
- 시킨 것: `git push origin main` 출력(`c802389..441d808 main -> main`)을 붙여 넣고 "push를 했는데 실제 깃허브에는 올라가지 않아"
- 얻은 것:
  - 원격 브랜치와 기본 브랜치 설정을 확인하고 리포를 직접 클론해 비교 → push는 정상 반영됨(원격 main 최신 커밋 = `441d808`, 기본 브랜치 `main`)
  - 원인 설명: GitHub은 push 시각이 아니라 커밋 작성 시각을 보여 주므로, 전날 만든 커밋을 나중에 올리면 새로 올라간 게 없어 보일 수 있음
  - 그 밖의 확인 항목: 브라우저 캐시, 리포 주소(포크·다른 계정 여부), 브랜치 선택 드롭다운, `.gitignore`로 빠진 파일
