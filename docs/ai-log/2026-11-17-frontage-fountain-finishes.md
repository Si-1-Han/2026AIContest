# 대학원관 보도·분수·정문 경계 수정

사용자 제공 화면과 추가 설명을 기준으로 수정했다. 실제 측량값을 새로 확보한 작업은 아니다. 앞선 본관 2층/주차장 평지 및 좁은 1층 하행 입구는 유지한다.

## 반영

- 대학원관→디자인관→GEMI→음악관→영산비전센터의 건물 쪽 빈 잔디 띠를 보도로 연결했다. 차도, 건물, 주차장, 차량 진입부, 옹벽 영역을 먼저 빼고 채운다.
- 이 구간의 건물 쪽 자동 수목을 전체 제외했다. 수목은 맞은편 보도 밖에 남긴다. 음악관 옆의 별도 잔디 상판과 관목도 제거했다.
- 분수 포장을 기존의 넓은 다각형에서 반경 8.2m 원형으로 축소했다. 수조 반경은 3.35m→5.2m로 확대했고, 교명 받침도 수조 바깥으로 옮겼다.
- 분수를 가리지 않는 원호 보행 경로와 왼쪽 운동장 사잇길을 연결했다. 사잇길과 운동장은 같은 수평 높이이며, 분수 접근부의 높이만 연속적으로 연결한다. 지형 보정 범위와 포장 면적을 분리해 포장을 줄여도 분수 앞에 잔디 언덕이 재생성되지 않게 했다.
- 정문 석재 외벽 안쪽 면을 1.8m 보도 끝에 맞췄다. 벽 바닥의 잔디도 정확히 잘라냈다.
- 도로와 양쪽 보도를 주차장보다 먼저 분할해 동일한 횡단 높이로 생성한다. 포장 경계의 잘린 잔디 정점도 동일한 고도 함수로 평가한다.
- 음악관 옆 높은 포장면은 수평 상판으로 만들고 옹벽 자리를 포장에서 제외했다. 두 주차장 진입로는 일정한 경사와 닫힌 측면을 갖도록 정리했다. 차량 진입면 안에 인도 조각이 남지 않는다.

## 검증

- 거리뷰 네트워크 300개 지점/309개 구간과 모든 건물·야외시설 접근 검사.
- 본관 전용 검사: 실제 보행면 126곳, 1·2·3층 접근과 주차장/외벽 접점.
- 노면 검사: 정문 435개 표본, 전체 도로/보도 횡단면, 주차장 실제 메시 754곳, Blender 소스 해시 일치.
- 상세 메시 검사: 건물 쪽 보도 184곳, 사잇길 평지 70곳, 음악관 수평 포장 20곳, 차량 진입 경사 24곳, 본관 평지 646곳, 실제 오르막 횡단면 284곳.
- 기존 주차선 규칙 1,009개 정점, 옹벽 지지 17곳, 1층 난간 58개 검사 유지.
- TypeScript/Vite 빌드 및 공백 오류 검사.

## Blender 및 브라우저

`assets/tour/campus-pavement.blend`, `assets/tour/campus-site.blend`를 실제 웹 메시로 갱신했다. 검토 이미지는 `assets/tour/reviews/2026-11-17/`의 `graduate-frontage`, `fountain`, `fountain-link`, `gate-uphill`, `music-uphill`, `music-parking-edge`, `main-entry-split`이다. 검토용 나무 수관은 단순화되어 있고 교명 텍스트는 브라우저와 동일하게 렌더하지 않는다.

Chrome에서 캠퍼스 탭을 확인한 뒤 네이티브 도구가 `elementHasNoFrame`/`noWindowsAvailable` 오류를 반복했다. 사용자가 허용한 Safari에서 실제 음악관 옆 주차장 경계의 접힌 타일을 확인하고 추가 수정했다. 수정 후 회귀 검사와 Blender 렌더로 확인했다. 이후 Safari 네이티브 연결도 `noWindowsAvailable`이므로 **최종 패치 이후 브라우저 전 구간 재검토는 완료로 기록하지 않는다.**
