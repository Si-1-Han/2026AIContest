# AI 활용 기록

콘테스트 평가에서 "AI를 얼마나, 어떻게 활용했는가"를 숫자로 보여주기 위한 기록입니다.
작업 세션이 끝날 때마다 아래 형식으로 파일을 하나 추가하세요.

- 파일명: `YYYY-MM-DD-이름-주제.md` (예: `2026-11-04-한시원-데이터변환.md`)

```markdown
# 2026-11-04 · 한시원 · 데이터 변환 스크립트

- 도구: Claude Code (모델명)
- 시킨 것: HMH geojson을 로컬 미터 좌표 JSON으로 변환하는 스크립트 작성
- 얻은 것: scripts/convert-geojson.ts, 건물 11개 동 변환 확인
- 사용량: 입력 ○○k / 출력 ○○k 토큰, 프롬프트 ○회
- 사람이 고친 부분: 좌표 축 방향 수정
```

에셋(음원·이미지·나레이션)을 생성했다면 **사용한 도구, 프롬프트, 라이선스(공개·상업 이용 가능 여부)** 를 함께 기록합니다.
