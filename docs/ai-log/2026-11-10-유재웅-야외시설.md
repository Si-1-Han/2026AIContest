# 2026-11-10 · 유재웅 · 캠퍼스 야외시설 추가

- 도구: Codex
- 시킨 것: 운동장·테니스장·교내 주차 구역 전체를 지도에 추가
- 후속 요청: 야외시설을 장소 검색·길찾기의 출발·도착지로 등록
- 출입구 요청: 사용자 이미지에 표시한 정문·당정역 방향 입구·당정초 방향 입구를 지도·검색·길찾기에 등록
- 표시 개선: 야외시설은 작은 이모지로 표시하고 장소명은 해당 시설이나 이모지에 커서를 올렸을 때만 표시. 키보드 포커스에서도 이름 확인 가능
- 얻은 것: OSM에 등록된 교내 야외시설 5곳(운동장 1, 테니스장 1, 주차 구역 3)의 외곽선 데이터, 파이프라인 변환, 3D 바닥·선·이름표 표시
- 자료: 기존 OSM 원본에 Map API에서 조회한 야외시설 way 5개 보완. 상세 출처는 backend/data/raw/README.md
- 후속 구현: 중앙·북측·남측 주차장 구분, 검색·자연어 안내 색인 확장, 지도 클릭·정보 패널·카메라 연결, 보행로 접근 노드 연결 및 서버·브라우저 경로 계산. 실제 출입구가 없는 야외시설은 접근 지점을 추정했다고 안내
- 검증: 백엔드 테스트 30개, 프론트 검색·안내·패널·지도 선택 및 브라우저 경로 69개, Ruff 검사·포맷 검사, 타입 생성 일치 검사·웹 빌드 통과. 본관·입구·보행로 좌표를 2D 검토 이미지로 대조. 실제 3D 화면의 육안 확인은 미완료
- 재생성: 기존 원본에 있는 학생회관 학회실 명칭(컴퓨터공학과 학회실)도 생성 JSON에 반영됨
- 제한: OSM에 미등록된 주차 구역은 추가 확인 필요. 경기장 선은 식별용 표현
- 사용량: 확인 가능한 토큰 통계 없음
- 출입구 구현: 사용자 지도와 기존 도로를 대조해 좌표 설정. 기존 도로를 교문 노드에서 나누고 당정역 방향 입구의 누락 통로 보완. 출입구 좌표는 근사값이며 관리 정보는 backend/data/GATES.md
- 사람이 고친 부분: 후속 검토 예정
